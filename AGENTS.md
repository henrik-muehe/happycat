# Happy Cat Star Improvements

A public collection of modifications to the Grabner Happy Cat Star.

## Content

- Keep each modification in `modifications/<descriptive-name>/` with its own `README.md`.
- Include the files, photos, and instructions needed to reproduce the modification.
- Link documented modifications from the root README.
- Clearly distinguish tested modifications from work in progress.

## Version Control

- This project uses Git and is intentionally public on GitHub.
- Commit with meaningful messages and push after significant changes.
- Never commit secrets, credentials, or private information.
- Keep temporary work under `tmp/`; do not commit it.
